### 🏛️ Flagship Production Architectures

#### 1. Samarth English Medium School Management & Distributed Archival System
*Full Stack Developer • Node.js, Express, React, PostgreSQL, Tailwind CSS, Vite, Tailscale VPN, Linux/Fedora*
- **Hybrid Edge-Cloud Document Archive**: Designed a zero-cloud-cost document archiving pipeline capable of storing **100,000+ student records (1 TB+)** on an on-premise Fedora server connected securely via a private Tailscale mesh VPN.
- **Resilient Sync & File Sharding**: Implemented a **2-level deterministic sharding directory scheme** and an idempotent queueing mechanism using **SHA-256 integrity validation**, `.part` streaming buffers, and atomic file operations to eliminate filesystem bottlenecks.
- **Full-Stack School ERP Features**: Built and optimized responsive portals for Admins, Teachers, and Parents, including student management, real-time fee tracking, payment gateway integrations, and automatic session inactivity timeouts.
- **Database & Query Performance**: Designed robust PostgreSQL schemas with **`BIGINT` precision** for large file metrics, optimized complex relational queries, and implemented column-aliased APIs for legacy DB compatibility.

---

#### 2. Smart CLM: Enterprise Contract Lifecycle Management
*Full Stack Developer • Spring Boot 3.5 (Java 21), React 18, PostgreSQL, Docker, Python ReportLab*
- **8-State Automated Transition Engine**: Engineered an enterprise CLM platform with role-based access control, digital signatures, dynamic approval matrices, and asynchronous webhook notifications.
- **Dynamic PDF Compilation**: Automated high-fidelity legal document generation containerized with Python ReportLab inside Docker.
- **IJERT Approved Research**: Co-authored a peer-reviewed research paper on the platform architecture and workflow engine, approved for publication in IJERT.
